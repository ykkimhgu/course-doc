#### **Presentation with Demovideo**

The presentation is oral presentation with PPT. &#x20;

**Presentation: < (5 min oral+ 2min demoVid)**&#x20;

* Introduction
  * Background and Problem Statement
* Project Objective
  * A list of Missions/Tasks&#x20;
* Project Design
* Results:  Demo Video
* Analysis
  * &#x20;Summary of Results, Evaluation Index etc
* Conclusion



**Demo Video:  <2min**

The demo video should be in English and it must contain

* Title Page
  * Project Title, Course name and Professor's name, Date, Your name, Organization
* Introduction
  * Background and Problem Statement
* Project Objective
  * A list of Missions/Tasks&#x20;
* Demonstration
* Conclusion&#x20;
